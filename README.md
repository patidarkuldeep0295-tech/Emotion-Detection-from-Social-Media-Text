Emotion Detection from Social Media Text

About the Project

Emotion Detection from Social Media Text is a machine learning project that identifies emotions from text entered by the user. It is developed using Python and Streamlit.

The main aim of this project is to understand the emotions expressed through text.

Features

- Detects emotions from text.
- Simple and user-friendly interface.
- Uses machine learning for emotion prediction.
- Displays five emotion categories.

Emotions Detected

- Happy
- Sad
- Angry
- Fear
- Surprise

Technologies Used

- Python
- Machine Learning
- Pandas
- Scikit-learn
- Streamlit

How to Run the Project

1. Install Python on your computer.
2. Clone or download this repository.
3. Open the project folder in VS Code.
4. Open the terminal and install the required libraries.
5. Activate your virtual environment.
6. Run the application using:

streamlit run app.py

Project Purpose

This project is created for learning purposes as part of Social Media Analytics and Distributed Computing. It helps understand how machine learning can be used to identify emotions from text.
